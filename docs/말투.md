# 인물별 말투표 (2026-11-11)

한 인물은 «상대»에 따라 한 가지 말투만 쓴다(문장마다 원문 어감 따라 바꾸지 말 것). [[feedback_consistent_speech_register]]
검사: 화자(웨이브·자막 키 이름)별 문장 끝 분포.

## 앨리스 (19세, 런던 / 원더랜드)
| 상대 | 말투 | 비고 |
|---|---|---|
| 혼잣말·관찰·일지 | 반말(-어/-야/-지, 일지는 -다) | 상대 없는 대사 대부분 |
| 체셔 고양이 · 모자장수 · 3월 토끼 · 겨울잠쥐 · 가짜 거북 · 목수 · 공작 부인 · 트위들 · 하트 여왕 · 원더랜드 주민 | 반말 | 친숙하거나 적대적 |
| 애벌레 · 하얀 왕 · 종이접기 개미 장로 | 해요체 | 존중하는 상대 |
| 범비 박사 · 윌슨 박사 · 래드클리프 변호사 · 유모(낸 샤프) · 런던의 어른 | 해요체 | |
| 범비 — 정체가 드러난 뒤(5_12·6_1 대결) | «당신»+반말 | 경멸 |
| 프리스 위트리스 | 해요체(비꼬는 존대, «위트리스 간호사님») | 원문이 Nurse Witless 로 깍듯이 비꼼 |
| 잭 스플래터 · 경찰 · 깡패 · 부두 노동자 · 추근대는 남자 | 반말 | 적대·경멸(비꼬는 말도 반말) |
| 리지(언니)·부모 | 반말 | 가족 |

## 안내·설명문
- 조작 안내·튜토리얼·로딩 힌트 = 해요체(-세요/-습니다 혼용 금지 → «-세요»·«-습니다» 평서). 버튼 행동 라벨은 명사형(«막기», «주시»).
- 목표(OBJECTIVES) = «-하라» 명령형.
- 일지·기억 조각(앨리스 일지) = «-다» 체.
- 친구와 적(설명) = «-다» 체.
