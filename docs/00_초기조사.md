## 구조 메모
- COALESCED: 빅엔디언 FString, UTF-16 문자 데이터는 리틀엔디언. 무수정 왕복 바이트 동일(추출 때마다 검산).
- 동영상 `MOVIES/*.TXT` 134개 = `시작ms, 끝ms, Subtitles.int 키` 뿐 → 번역 대상 아님.
- 음성 자막: 언어별 패키지 전부에 6개 언어가 구워져 있고 엔진은 INT 엔트리. 같은 웨이브가 여러 패키지에 있어도 INT 문장은 동일(검산). 재삽입 = `tools/build_subs.py` 방식(INT 엔트리 Text 교체, 오프셋·벌크 재계산, 이득 없는 블록 무압축).
- ★PC 판 VO .int 의 큐 1,953개 중 1,391개는 PS3 패키지 이름표 어디에도 없다(전수) → PS3 에 없는 대사. 번역 불필요.
- 웨이브 678개 중 119개는 모든 언어 자막이 비었고, 12개는 JPN 에만 문장이 있다(INT 없음 → 영어판도 자막 없음, 대상 아님).
- 폰트 두 갈래: 메뉴 = GFx `ALICEFONTS.XXX` fonts_en / 자막·로딩 = UE3 UFont `WarfareFonts_Chrom20`(`ALICEGAME_LOC_INT.XXX`·`ALICEFONTS_LOC_INT.XXX`). FFontCharacter = i32×4 + u8 + i32(비정렬). 상세는 이식 폴더 `patches\읽어보세요.txt`.
